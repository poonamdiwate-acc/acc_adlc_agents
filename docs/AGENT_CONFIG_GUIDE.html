JSON Schema definition. Both scripts use this. Keep in same folder as the scripts.

⚠ Rules — every developer must follow these
✗ Never copy from another agent's config — always use the generator or template
✗ Never manually edit agent.id format — use phase prefix: PL / DE / BU / VA / OP or GW for GenWiz
✗ Never change run_id_source or thread_id_source — these are system-wide constants
✗ Never add iteration_1 or iteration_2 wrappers — flat structure only
✗ Never add on_gap, retry_attempts, confidence_threshold to llm_config_override — inherited from tech stack
✓ Always run validate_config.py before submitting a PR
✓ Always create SKILL.md after config — config is the source of truth for SKILL.md
✓ Always update GenWiz sequence when adding a new ADLC agent
