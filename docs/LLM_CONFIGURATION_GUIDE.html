LLM Configuration Guide

Version: 2.0.0  |  Last Updated: 2026-05-19

1. Overview — Two Modes (Mutually Exclusive)

Standard LLM
Direct SDK calls per provider
mode: "standard"
⇄
LiteLLM
Unified routing via LiteLLM library
mode: "litellm"
Rule: Only one mode can be active at a time. When Standard is ON, LiteLLM is OFF — and vice versa.

2. Configuration File

The primary toggle lives in configs/ADLC_Tech_Stack_Config.json under the "llm" block:

{
  "llm": {
    "mode": "standard",              // "standard" | "litellm"
    "active_provider": "google-vertex",  // used by both modes
    "active_model": null,            // optional model override (standard mode)
    "response_format": "json",
    "stream": false,
    "providers": { ... }
  }
}

3. Standard LLM Mode

3.1 How to Enable

{
  "mode": "standard",
  "active_provider": "google-vertex"
}

Or via environment variable: LLM_MODE=standard

3.2 Selecting a Provider

ProviderConfig ValueSDKDefault Model
Google Vertex AI"google-vertex"google-genaigemini-2.5-flash
AWS Bedrock"aws-bedrock"boto3anthropic.claude-3-5-sonnet-20241022-v2:0
Azure OpenAI"azure-openai"openaigpt-4o

3.3 Overriding the Model

Set "active_model" to use a specific model instead of the provider's default:

{
  "active_provider": "google-vertex",
  "active_model": "gemini-2.5-pro"    // overrides default "gemini-2.5-flash"
}

Set to null to use the provider's default_model.

3.4 Required Environment Variables

Google Vertex (default)

GOOGLE_CLOUD_PROJECT=your-gcp-project-id
GOOGLE_CLOUD_LOCATION=us-central1
GOOGLE_APPLICATION_CREDENTIALS=C:\path\to\service-account.json

AWS Bedrock

AWS_ACCESS_KEY_ID=AKIAxxxxxxxxxxxx
AWS_SECRET_ACCESS_KEY=xxxxxxxxxxxxxxxx
AWS_REGION=us-east-1

Azure OpenAI

AZURE_OPENAI_API_KEY=your-api-key
AZURE_OPENAI_ENDPOINT=https://your-resource.openai.azure.com
AZURE_API_VERSION=2024-06-01

3.5 Per-Agent Overrides

Each agent config can override max_tokens and timeout_seconds via llm_config_override:

// In PL-01_Gap_Detection_Config.json
{
  "llm_config_override": {
    "max_tokens": 16384,
    "timeout_seconds": 180
  }
}

4. LiteLLM Mode

4.1 How to Enable

{
  "mode": "litellm",
  "active_provider": "azure-openai"    // maps to [azure] section in llm_config.ini
}

Or via environment variable: LLM_MODE=litellm

4.2 Configuration File

LiteLLM reads its settings from core/litellm/llm_config.ini:

[appsettings]
default_llm_provider = azureopenai
default_model_name = gpt-4.1
use_litellm = true
enable_cost_tracking = true
num_retries = 3
timeout_seconds = 600

[litellm_gateway]
use_proxy = false
proxy_url = http://localhost:4000
model = azure/gpt-4.1
key = sk-your-proxy-master-key

[azure]
api_key = YOUR_AZURE_API_KEY
endpoint = https://your-resource.openai.azure.com
api_version = 2024-12-01-preview
deployment_name = gpt-4.1
model = azure/gpt-4.1
temperature = 0.7

[bedrock]
model_id = anthropic.claude-3-5-sonnet-20241022-v2:0
region = us-east-1
aws_access_key_id = YOUR_AWS_ACCESS_KEY
aws_secret_access_key = YOUR_AWS_SECRET_KEY

[vertex]
model_name = gemini-1.5-pro
project_id = your-gcp-project
location = us-central1

4.3 Provider Mapping

active_provider (JSON)INI SectionLiteLLM Model Prefix
google-vertex[vertex]vertex_ai/
aws-bedrock[bedrock]bedrock/
azure-openai[azure]azure/

4.4 Proxy Mode (Optional)

Set use_proxy = true in [litellm_gateway] to route all calls through a centralized LiteLLM proxy server instead of making direct SDK calls:

[litellm_gateway]
use_proxy = true
proxy_url = http://your-litellm-proxy:4000
model = azure/gpt-4.1
key = sk-your-proxy-master-key

5. Quick Reference — Switching Modes

I want to...Change in ADLC_Tech_Stack_Config.json
Use Google Vertex directly"mode": "standard", "active_provider": "google-vertex"
Use Azure OpenAI directly"mode": "standard", "active_provider": "azure-openai"
Use AWS Bedrock directly"mode": "standard", "active_provider": "aws-bedrock"
Use a specific model"active_model": "gpt-4o-mini" (with appropriate provider)
Switch to LiteLLM"mode": "litellm" + edit core/litellm/llm_config.ini
Override at runtimeSet env var: LLM_MODE=litellm or LLM_MODE=standard

    │
    ▼

    ├── mode = "standard"
    │       │
    │       ▼

    │       ├── google-vertex → google-genai SDK
    │       ├── aws-bedrock   → boto3 Bedrock Runtime
    │       └── azure-openai  → openai AsyncAzureOpenAI

            │
            ▼

            │
            ▼
        LiteLLMFactory.create_from_config_ini  ← core/litellm/litellm_factory.py
            │
            └── reads core/litellm/llm_config.ini

7. Testing Checklist

Standard Mode (Google Vertex — default):
  1. Ensure "mode": "standard" in config
  2. Set GOOGLE_CLOUD_PROJECT, GOOGLE_CLOUD_LOCATION, GOOGLE_APPLICATION_CREDENTIALS
  3. Set ADLC_API_KEY for auth
  4. Run server: python run.py
  5. Hit any agent endpoint with X-Thread-ID and X-Run-ID headers
LiteLLM Mode (Azure example):
  1. Set "mode": "litellm", "active_provider": "azure-openai" in config
  2. Fill in [azure] section in core/litellm/llm_config.ini
  3. Run server: python run.py
  4. Hit any agent endpoint — calls route through LiteLLM
